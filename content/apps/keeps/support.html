How can I get Keeps?

Keeps is currently in private TestFlight testing. There is no public download link yet. Contact Chen about availability.

Which devices are supported?

Keeps supports iPhone and iPad running iOS or iPadOS 18 or later, and Mac running macOS 15 or later.

Where should I start?

Try the separate demo collection, or add a few belongings you use regularly. The getting-started guide walks through photos, usage, costs, and backups.

Why is an item not appearing on another device?

Check that both devices use the same iCloud account, Keeps is using the personal collection, and iCloud sync is enabled. Check the sync status in Settings and use its refresh control with an internet connection. Allow time for photos to transfer. If an error persists, send the error text and app version to support.

Does importing a backup replace my collection?

In a synced personal collection, Import backup as new items adds new copies without deleting existing items. Repeated imports can create duplicates. In local or demo mode, Restore backup replaces the current collection after confirmation. Export a backup first and read the confirmation carefully.

Why is a converted amount different from my card charge?

Keeps uses reference exchange rates, which may differ from your bank’s rate or include a different effective date. Card fees are not included. Original purchase amounts and currencies remain unchanged. Missing conversions do not prevent you from saving an item.

Does Keeps estimate what my items are worth today?

No. The totals describe recorded purchase costs and ownership costs. A latest-rate currency equivalent converts the original purchase amount; it is not a resale valuation.

Why does a web photo search or download fail?

A search provider may show a verification page, or an image host may block downloads. Some images may exceed the supported size or format. Try a different result, another provider, or a photo you select from your device.

Does switching off sync delete my data?

No. It pauses synchronization. To remove an item across devices, delete it while sync is enabled and let the change synchronize. Exported backups must be deleted separately. See the privacy policy for details.

Is there a backup size limit?

The current backup format has a 100 MB encoded file limit. Photos are included in that size. If a backup cannot be exported or imported, contact support before removing any items.

Reporting a problem

Email chen.he@icloud.com with your device model, system version, Keeps version and build from Settings, and the steps that led to the problem. Include the exact error if there is one.

A screenshot can help. Remove personal item details before sharing, and send a collection backup only if you choose to after discussing the issue.
