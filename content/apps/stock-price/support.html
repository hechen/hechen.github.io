Stock Price support

Setup help, troubleshooting, and source code.

Quick setup

  1. Install the plugin and add Stock Quote to a Stream Deck key.
  2. Select Alpha Vantage or Finnhub.
  3. Save your provider API key in Shared plugin settings.
  4. Enter a stock symbol and choose the displayed change and background style.

Read the complete setup guide →

Cached or delayed values

The plugin caches quotes and enforces request limits to avoid exhausting free API plans. Weekly change may require enough locally observed history, depending on the selected provider.

Get help

Report a problem or request a feature through GitHub Issues. Include your Stream Deck version, operating system, provider, symbol, and visible error—but never include your API key.
