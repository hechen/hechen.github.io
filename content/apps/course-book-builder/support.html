Getting started

Course Book Builder is currently a preview and has not been released on the Chrome Web Store. This page will link to the official listing when it is available.

  1. If you already have the preview, open a normal webpage and click the extension icon.
  2. Use Add current page for an article, Find linked pages to review candidates, or Scan current tab for a supported course outline.
  3. Select your pages, edit the reading order, and choose Export EPUB. Unsaved selected pages are captured automatically.
  4. For PDF, use the PDF export action and save from your browser's print dialog. Keep the builder open while work is running.

A website did not parse correctly

Choose Details / report on the affected page, or Report issue in the header. Describe what you expected and what the export contains—for example, the last heading captured, a missing diagram, or code that lost indentation.

Page addresses and capture counts are off by default. Include a public address only if you are comfortable sharing it. Credentials, query parameters and fragments are stripped from the report address, but its path may still identify private content.

Review the editable report, then choose Open email draft. Your email app prepares a message to chen.dev@icloud.com; you decide whether to send. If no email app opens, use Copy report or Download report and email it yourself. Do not send passwords, cookies, access tokens, private course exports or other sensitive content.

Common checks

  • Missing sections or images: confirm the original page fully loads while signed in, check its capture warnings, and refresh one saved page before exporting again. A saved counter is not a completeness check.
  • Only one page found: that is expected for ordinary articles. Find linked pages lists candidates for manual selection. Course-outline discovery varies by website.
  • Toolbar does not open: reload the extension when it is idle and retry on an ordinary HTTP/HTTPS webpage. The compact-window fallback is intended for browsers without reliable native side-panel opening; Arc validation is still in progress.
  • Stopping a long capture: Cancel keeps completed pages. Start capture or export again to collect the remaining selected pages; keep the active builder view open while it works.
