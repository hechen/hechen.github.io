Structly

Support

Last updated: 16 August 2026

Start here if Structly says the Safari extension is not enabled.

Enable Structly on iPhone or iPad

  1. Open any webpage in Safari.
  2. Tap the Page Menu beside the address, then tap Manage Extensions.
  3. Turn on Structly. If Safari asks, allow access to websites.
  4. Return to the Structly app. The extension status refreshes to a green Enabled checkmark.

Alternative: Settings

iOS or iPadOS 18 and later:
Settings → Apps → Safari → Extensions → Structly

iOS or iPadOS 17:
Settings → Safari → Extensions → Structly

Enable Structly on Mac

Open Safari → Settings → Extensions, select Structly, and turn it on. Allow website access when Safari asks.

Sync between devices

Nothing to set up. Preferences sync over iCloud automatically when you're signed into the same Apple ID.

Safari updated and the extension stopped working

Usually a permissions reset. Open Safari's Page Menu → Manage Extensions, toggle Structly off and back on, and allow website access again if Safari asks. If it is still off, restart Safari once.

The extension didn't format a page

Structly only triggers on responses Safari recognises as JSON (Content-Type: application/json). Pages that send JSON with text/html or text/plain headers won't trigger automatically. Reload with the URL bar focused and Structly should pick it up on the second pass.
