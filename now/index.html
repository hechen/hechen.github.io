Tools I'm using

The full list is at /tools. Daily drivers right now:

  • Xcode 16 + SwiftUI + SwiftData — the whole stack stays Apple-native. SwiftData is finally stable enough for shipping.
  • Apple MLX — on-device LLM backend for the AI features in LiftCoach, EatWisely, Closet, TrainInsight. Replaced the dead eastriverlee/LLM.swift dependency in CHSharedKit 2.5.
  • Claude Code — most of the boilerplate, scaffolding, and refactors flow through here. I drive the architecture; it executes the keystrokes.
  • Things 3 + Linear — Things for personal todos, Linear for cross-app issue tracking.
  • GitHub Pages + Tailwind CDN — this site. No build step, fast iteration.

Reading

  • Apple's Designing for visionOS docs — not building for Vision Pro yet, but the spatial-design principles are leaking back into iPad layout decisions
  • The App Intents WWDC sessions — DupeOut just shipped Siri Shortcuts in Build 62 (support docs) and the affordance is genuinely useful
  • Tao Te Ching (Mitchell translation) — re-read every couple of years; resets my pace

Not working on

Listing the things I've explicitly deprioritized so they don't sneak back in:

  • Web apps. The portfolio is iOS / macOS / watchOS. Web is for marketing pages only.
  • Cross-platform frameworks. Flutter, React Native, etc. Native Apple stack is what I want to ship.
  • Backend services. Every app is on-device or iCloud-direct. No DupeOut server, no LiftCoach server, no EatWisely server.
  • Subscriptions. One-time purchases or free. Re-evaluating only if a feature genuinely requires recurring server costs.
