Structly

Beautiful JSON formatting Safari extension for macOS and iOS.

Structly turns raw JSON in your browser into a clean, color-coded, searchable view. A must-have tool for developers.

Features

  • Syntax highlighting — Color-coded JSON for easy reading
  • Search — Find keys and values instantly with Cmd+F
  • JSON Path queries — Filter with jq-like syntax using Cmd+G
  • Export — Convert to YAML, CSV, or TypeScript interfaces
  • Smart detection — Auto-formats Unix timestamps, URLs, and Base64 strings
  • Light & dark themes — Matches your system appearance
  • Keyboard shortcuts — Power-user friendly with full keyboard navigation
  • Cross-platform — Works in Safari on both iOS and macOS
