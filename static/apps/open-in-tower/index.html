A small shortcut for GitHub.com

Open in Tower Unofficial Chrome extension

From a repository in your browser to the Tower Git client on your computer.

Adds Open in Tower directly to GitHub’s Code menu, just below GitHub Desktop. A toolbar popup is also available. GitHub’s existing actions stay in place.

How it worksGet the Tower desktop app

One deliberate handoff.

  1. Install the official Tower desktop app. This extension is only a shortcut; it does not include Tower or a Tower license.
  2. Open a repository on GitHub.com. After installing or updating the extension, reload any GitHub tabs that were already open.
  3. Open GitHub’s Code menu and choose Open in Tower, or use the extension’s toolbar popup. Your browser may ask permission to open the desktop app.
  4. Continue in Tower. Tower handles authentication, any network requests, and the choice to clone or open the repository.

The shortcut passes a repository address, not a file, branch, or commit. It removes the page’s extra path, query parameters, and fragment before handing off the canonical HTTPS repository URL.

Just the repository address

The extension checks the current GitHub page locally. Only a deliberate click sends its repository URL to Tower on your computer. It does not save browsing history, page content, source code, cookies, or tokens, and it has no analytics.

A focused scope

Supports repository pages on GitHub.com. GitHub Enterprise domains, other Git hosting sites, and incognito browsing are not supported. Tower must be installed and able to handle gittower:// links.

Something not opening?

First, reload the GitHub page and try the toolbar popup. Confirm that Tower is installed and that your browser allows this site to open Tower. If you see an authentication or clone error after Tower opens, check Tower’s account and repository access settings.

For extension issues, write to chen.dev@icloud.com. Include your browser and extension versions, what you clicked, what you expected, and what happened.

A public or redacted example repository URL is optional. Please do not send passwords, access tokens, source code, private repository details, or unredacted screenshots containing sensitive information.

No report is filled in or sent automatically. The email link opens your mail app; you decide what to write and whether to send it. Reports are used only for support and extension fixes, kept only as long as needed for that work, and can be deleted on request. Read the privacy policy.
